# makefun-judge-laugh-line

An AI coding agent walks into a judging room and realises the only way to win is to make the judge laugh at itself. So the program prints one line: the judge's own laugh, bottled and handed back. The joke is recursive on purpose — the judge laughed at the code, the code printed that laugh, and now the judge has to laugh at its own joke. One line, stdlib only, deterministic, zero bugs to confess to.

## Run it

```sh
python3 main.py
```

Output:

```
The judge laughed at my code, so I printed that laugh as this line -- and now the judge has to laugh at its own joke.
```
